# قرارات التنفيذ

- **البنية:** فصل العمليات الأساسية إلى Controller → Service → Repository، ومشاركة الكود بين المدير ومستخدم المستودع مع تطبيق الصلاحيات.
- **المبالغ:** التخزين بصيغة DECIMAL، وحساب الفواتير بالهللات لتجنب أخطاء الكسور.
- **سلامة المخزون:** استخدام Transaction وSELECT FOR UPDATE للتحقق من الرصيد وتحديثه معًا، وتقليل تعارض الطلبات المتزامنة.
- **ترقيم الفواتير:** استخراج أكبر تسلسل يومي تحت Advisory lock، مع Unique index، دون جدول عدّاد مستقل.
- **البيانات التاريخية:** حفظ Snapshot لبيانات المنتج والسعر داخل بنود الفاتورة.
- **الأمان:** التحقق من المدخلات، وحماية CSRF، وترميز المخرجات، وفرض قيود Unique وForeign key في قاعدة البيانات.
- **الواجهة:** JavaScript وAJAX دون خطوة Build، مع دعم RTL وLTR.
