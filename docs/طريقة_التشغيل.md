# التشغيل والاستخدام


1. نفّذ `composer install`.
2. انسخ `.env.example` إلى `.env` واضبط بيانات MySQL و`CI_ENCRYPTION_KEY`، واجعل `APP_BASE_URL=http://localhost:8080/`.
3. جهّز قاعدة البيانات بإحدى الطريقتين فقط:

   **Migrations (المفضلة):** أنشئ قاعدة MySQL فارغة بالاسم المحدد في `DB_DATABASE` (الافتراضي `mini_erp_smart_life`)، ثم نفّذ:

   ```sh
   php index.php cli/migrate
   php index.php cli/seed
   ```

   **استيراد SQL:** استورد `database/schema.sql`؛ ينشئ القاعدة باسم `mini_erp_smart_life`. اجعل `DB_DATABASE` مطابقًا، ثم نفّذ `php index.php cli/seed` فقط، دون migrate.

4. شغّل `php -S localhost:8080 index.php` وافتح http://localhost:8080.
5. ادخل بحساب المدير `test@smartlife.com` وكلمة المرور `87654321`.

   حسابات مستخدمي المستودعات (كلمة المرور `87654321`): الرياض `ahmed@smartlife.com`، جدة `sara@smartlife.com`، الدمام `khalid@smartlife.com`.

6. أضف المنتجات، وعدّل المخزون من صفحة المخزون، ثم أنشئ فاتورة باختيار العميل والمستودع والمنتجات والكميات.

   مستخدم المستودع: اعرض مخزون مستودعك وتقارير النقص، وأنشئ الفواتير واعرض تفاصيلها أو ألغِها لاستعادة المخزون.
